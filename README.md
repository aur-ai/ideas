# Little Focus

A simple, responsive Pomodoro timer built with plain HTML, CSS, and JavaScript. It runs entirely in your browser and can be hosted on GitHub Pages.

## Features

- 25-minute focus sessions, 5-minute short breaks, and 15-minute long breaks
- Automatically switches to a break after focus, and to a long break after every fourth focus session
- Start, pause, reset, and switch timer modes
- Saves the selected mode and completed focus sessions in your browser
- No build step or dependencies

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Deploy with GitHub Pages

1. Push these files to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your branch and the `/ (root)` folder, then save.

GitHub Pages will publish the app at the URL shown in the Pages settings.
